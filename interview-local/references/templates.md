# Templates

Replace every `{{...}}`. Omit executors the operator does not have. Never add secrets,
emails, or prices.

## .agents/roster.yaml

```yaml
version: 1

orchestrator: {{claude|codex}}
fallback_orchestrator: {{codex|claude|none}}

executors:
  claude:
    tier: {{plan tier, free text}}
    roles: [orchestrate, review]        # keep implementation off scarce quota
    default_model: {{sonnet-class slug from delegate-agent/references/model-index.md}}
    escalate_model: {{opus-class slug}}  # design decisions only
  codex:
    tier: {{plan tier}}
    roles: [implement, review]
  copilot:
    tier: {{plan tier}}
    roles: [batch, second-opinion]       # request-metered: few large, well-specified jobs
  agy:
    tier: {{plan tier}}
    roles: [research, docs, tests]       # large-context reading, separate quota bucket

project:
  build: "{{command}}"
  test: "{{command}}"
  lint: "{{command}}"

split_units:                             # exclusive writable areas for parallel workers
  - name: {{unit}}
    paths: [{{dir/}}]
risk_zones:                              # never delegated blind; review always required
  - paths: [{{dir/}}]
    policy: {{direct|review-required}}

max_workers: {{3}}
review:
  cross_executor: {{always|risk-zones-only}}   # reviewer differs from implementer
worktrees:
  dir: {{.worktrees}}
  branch_prefix: {{wt/}}
```

## AGENTS.local.md

```markdown
# Local orchestration config (not committed)

Generated by interview-local on {{YYYY-MM-DD}}. Machine-readable copy: `.agents/roster.yaml`.
Re-run interview-local if subscriptions or roles change.

## Roles
- Orchestrator: {{executor}}. Fallback when exhausted: {{executor|none}}.
- {{executor}}: {{roles, one line each}}

## Rules for the orchestrator
1. Read `.agents/roster.yaml` before decomposing. Delegate only to listed executors.
2. Define the interface and acceptance tests before dispatching workers.
3. Give each worker its own worktree and an exclusive writable path set from
   `split_units`. Workers must not edit outside it.
4. At most {{max_workers}} workers at once; queue the rest.
5. Read worker RESULT.md, the diff, and test output — not full transcripts.
6. Anything from a risk zone: {{direct|review-required}}. Code written by one
   executor is reviewed by a different one ({{always|risk-zones-only}}).
7. Check each adapter's preflight (quota/credits) at dispatch time; do not rely on
   remembered headroom.

## Commands
- Build: `{{command}}`
- Test: `{{command}}`
- Lint: `{{command}}`

## Risk zones
{{list, or "none"}}

## Personal rules
{{e.g. Do not commit or push unless asked.}}

## For workers
Read only the task brief and this file. Do not delegate further. Write RESULT.md
(summary ≤5 lines, tests run + result, deviations from the contract, blockers) and
stop. If blocked, record the blocker instead of guessing.
```
